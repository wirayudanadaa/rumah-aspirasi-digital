# CRITICAL BUG FIX — ADMIN DETAIL

## Root Cause
Bug ini merupakan regresi dari optimasi **PERF-02 (Explicit SELECT)**.
Pada halaman detail laporan admin (`src/app/admin/aduan/[id]/page.tsx`), query yang dikirimkan ke Supabase secara spesifik meminta kolom `phone`. Namun, berdasarkan skema tabel aktual `public.aduan` di database, kolom `phone` **tidak ada**. 
Karena query meminta kolom yang tidak terdefinisi, PostgREST merespons dengan HTTP Error 400 (Code `42703: column aduan.phone does not exist`). Blok `catch` pada `useEffect` kemudian menangkap error sistematis ini dan menampilkannya sebagai pesan generik kepada pengguna: *"Data aduan tidak ditemukan atau Anda tidak memiliki akses."*

## Fix
Fix dilakukan secara sangat spesifik dan minimal. Kolom `phone` yang memang tidak ada secara permanen dihapus dari string `SELECT` pada query di `src/app/admin/aduan/[id]/page.tsx`. Tidak ada modifikasi skema, tidak ada migrasi baru, dan tidak ada kolom tambahan yang dibuat.
